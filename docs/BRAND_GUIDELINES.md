# Pantry Brand Guidelines

## Brand Personality

Pantry should feel:
- modern
- optimistic
- rewarding
- health-forward
- premium
- approachable
- motivating
- clean

Pantry should NOT feel:
- clinical
- shame-based
- elitist
- overly scientific
- childish
- chaotic

---

## Product Feel

The emotional feeling should be:

"Healthy living feels rewarding, achievable, and motivating."

Users should feel:
- proud
- encouraged
- optimistic
- curious
- excited to return

---

## Design Inspiration

Primary inspiration references:
- Apple Health
- WHOOP
- Oura
- Duolingo (light gamification only)
- Fetch Rewards
- Linear
- Stripe

---

## UI Direction

### Core Principles
- Mobile-first
- Strong whitespace
- Clean card layouts
- Minimal clutter
- Large touch targets
- Fast visual feedback

### Avoid
- Data overload
- Tiny text
- Dense dashboards
- Excessive charts
- Aggressive warning systems

---

## Color Direction

Suggested direction:
- Deep greens
- Soft neutrals
- Cream/off-white backgrounds
- Lime accents
- Charcoal typography

Avoid:
- Neon overload
- Harsh reds
- Rainbow gradients
- Cheap wellness aesthetics

---

## Motion Direction

Motion should feel:
- smooth
- premium
- subtle
- intentional
- rewarding

Use motion for:
- score reveals
- points accumulation
- transitions
- success states
- card interactions

Avoid:
- excessive bouncing
- distracting animations
- gimmicky motion

---

## Typography

Typography should feel:
- modern
- readable
- premium
- mobile-friendly

Avoid:
- novelty fonts
- futuristic gimmicks
- compressed readability

---

## UX Writing Tone

Use language that is:
- encouraging
- simple
- motivational
- clear
- positive

Avoid:
- shame
- guilt
- harsh nutrition language
- fear-based copy

Examples:

Good:
- Great choices
- Nice balance
- Strong protein picks
- You earned points
- Keep the streak going

Bad:
- Poor choices
- Unhealthy cart
- Failed score
- Bad nutrition

---

## MVP UX Rule

The app should prioritize:
- quick understanding
- low friction
- repeat usage
- emotional reward

The key product loop:

Landing page -> receipt upload -> analysis -> points -> signup -> dashboard -> rewards.
